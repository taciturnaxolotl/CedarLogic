# Toolbar icons

These icons are derived from [Lucide](https://lucide.dev) (a fork of Feather),
licensed under the **ISC License**.

The path geometry is Lucide's; the presentation attributes were moved from the
`<svg>` root onto a wrapping `<g>` so wxWidgets' bundled nanosvg rasterizer
inherits them, and the stroke/fill color is recolored at load time to match the
active light/dark theme.
